## 4. How to Configure MetaMask

### Step 4.1: Add Hardhat Localhost Network
1. Open the MetaMask extension in your browser.
2. Click the **Network Selector** dropdown in the top-left corner.
3. Click **Add Network** &rarr; select **Add a network manually** at the bottom.
4. Enter the network details:
   - **Network Name**: `Hardhat Localhost`
   - **New RPC URL**: `http://127.0.0.1:8545` *(Tip: Use `127.0.0.1` instead of `localhost` to avoid browser resolution issues)*
   - **Chain ID**: `31337`
   - **Currency Symbol**: `ETH`
5. Click **Save**.

### Step 4.2: Import Test Accounts
1. In MetaMask, click on the account circle icon &rarr; select **Add account or hardware wallet** &rarr; **Import account**.
2. Select **Private Key** as the import type.
3. Paste the **Borrower Private Key** (`0x59c6...` above) and click **Import**. Rename the account to `Hardhat Borrower`.
4. Repeat the process to import the **Lender Private Key** (`0x5de4...` above) and rename it to `Hardhat Lender`.
5. You should now see an initial balance of `10,000 ETH` on both accounts.

### Step 4.3: Resetting MetaMask Nonce After Node Restarts
Whenever you stop and restart the Hardhat node (`npx hardhat node`), the blockchain starts fresh from Block 0. If you encounter a `Nonce too high` or `Internal JSON-RPC error` in MetaMask:
1. In MetaMask, go to **Settings** &rarr; **Advanced**.
2. Click **Clear activity tab data** (or **Reset Account** in older versions).
3. This clears cached transaction history and resynchronizes nonces with the fresh local node.

### Step 2: Deploy Contract and Sync Artifacts
Open **Terminal 2**:
```powershell
cd "c:\Users\Umer Khan\OneDrive\Desktop\BT Mini Project\blockchain"
npm run deploy:local
```
This automatically:
- Compiles `BlockLoan.sol`

- Saves artifacts to:
  - `blockchain/deployments/localhost.json`
  - `frontend/src/contracts/contractConfig.ts`
